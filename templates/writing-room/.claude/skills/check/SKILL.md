---
name: check
description: Check any file against RULES.md with the checker subagent and show the report. Usage: /check <file>
---

Use the **checker** subagent to check `$ARGUMENTS` against `RULES.md`. Show the report exactly as it comes back. Do not rewrite anything.

If the file is one of the writer's own published pieces (in `archive/`) and the checker flags lines in it, point that out: a rule that flags the writer's own best work is probably worded wrong. Offer to sharpen it with them.
