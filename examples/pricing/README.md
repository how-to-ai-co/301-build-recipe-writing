# Worked example: one piece through the loop

A freelance designer's newsletter, short so it fits on a screen. Their first six rules came from a blind rewrite in class.

| Step | File |
| --- | --- |
| 1. Idea | `idea.md` |
| 2. Draft (before the check) | `claude-first.md` |
| 3. Check | `check.txt`: five lines flagged against R1, R3, R4, R6 |
| 2 again. Fixed draft | `claude.md` |
| 4. The writer's edit | `mine.md` |
| 5. Learn | `learn.md`: 54% of Claude's words kept, three new rules |
| Rules after | `RULES.md`: R1–R6 from class, R7–R9 from this edit |

Real pieces are longer, and day-one kept-words numbers are usually lower.
